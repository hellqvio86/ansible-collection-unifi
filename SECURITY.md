# Security Policy

## Supported Versions

Security updates are provided for the latest released version of `hellqvio86.unifi`.

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of `hellqvio86.unifi` seriously. If you discover a security vulnerability in this project, please report it responsibly:

1. **Do not open a public GitHub issue.**
2. Report the vulnerability privately via [GitHub Security Advisories](https://github.com/hellqvio86/ansible-collection-unifi/security/advisories/new) or by contacting the maintainer directly via GitHub (@hellqvio86) or email (`olof.hellqvist@gmail.com`).
3. Include details to help reproduce and understand the issue:
   - Affected collection version(s)
   - Relevant module or utility (e.g. `unifi_api`, `unifi_ssl_config`)
   - Steps to reproduce or proof-of-concept playbook
   - Potential impact of the issue

### Response Timeline

- **Acknowledgment**: Within 48 hours of report receipt.
- **Assessment & Fix**: A fix or mitigation will be developed and tested.
- **Disclosure**: Coordinated public release after a patch is available on Ansible Galaxy.
